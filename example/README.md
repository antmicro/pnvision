# Example

This directory contains example scan data generated by the `openpnp_scripts/peform_inspection.py` script. The data can be used to test and demonstrate the capabilities of PnVision.

## Directory Structure
```
example/
├── board/
├── components/
├── README.md
└── report.json
```

* board/ – contains partial images from a PCB scan. These images can be stitched together to generate a complete PCB image using the `pnvision stitch` option.
* components/ – contains images of individual PCB components used for component inspection and comparison.
* report.json – an example JSON output generated by the framework. It can be used to generate an HTML report with `pnvision report report.json`.

## Usage

You can use the contents of this directory to try out the framework's commands.

For instructions on how to use the example data, see the [Quick Start guide](../doc/source/quick-start.md).
